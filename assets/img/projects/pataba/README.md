# PATABA project media

Upload public-safe portfolio images for the PATABA project in this folder.

Suggested files:
- `cover.png` — project card or page cover
- `homepage-concept.png` — public-facing homepage concept
- `wireframe.png` — UI/UX wireframe or prototype preview

Use `.png`, `.jpg`, or `.webp`. Keep images reasonably compressed. Since this collaboration is awaiting further coordination, only share approved concept material. Do not upload internal government asset records, confidential documents, or private data.
