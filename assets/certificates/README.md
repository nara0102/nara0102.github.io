# Certificate uploads

Upload certificate documents to this folder. The portfolio page at `/certificates/` will list each uploaded file and provide a preview when the file is a PDF or image.

Recommended formats: PDF, PNG, JPG, or JPEG. Use descriptive lowercase file names, for example:

- `belajar-git-github.pdf`
- `analisis-data-python.pdf`
- `machine-learning-pemula.pdf`

Please upload only certificate files you are comfortable making public. The CV page links to the certificate archive.
